Menu tunggal melibatkan siklus berulang (iteratif)

4. Hierarchical or Sequential Menus
•
Struktur hierarkis cocok digunakan ketika terdapat banyak
hubungan antar pilihan menu
•
Beberapa pilihan menu hanya tersedia berdasarkan pilihan
sebelumnya
•
Pada struktur top-down, urutan dan percabangan menu telah
ditentukan sebelumnya
•
Alur navigasi umumnya berjalan satu arah
•
Struktur hierarkis memiliki karakteristik depth dan breadth
Depth: jumlah tingkat menu yang harus dilalui untuk mencapai
tujuan
Breadth: jumlah pilihan yang tersedia pada setiap tingkat menu
© Politeknik Statistika STIS

The Shortcomings
•
Pengguna dapat memilih jalur yang salah jika tidak
memahami struktur menu
•
Pengguna mungkin perlu kembali ke menu sebelumnya atau
menu utama
•
Hierarki menu harus sesuai dengan harapan pengguna
•
Ketidakpastian pilihan harus diminimalkan
•
Navigasi kembali ke atas struktur menu harus mudah
dilakukan untuk mendukung eksplorasi menu

•
Menentukan jumlah item pada setiap menu (breadth)
•
Menentukan jumlah tingkat menu (depth)
Secara umum:
•
Semakin banyak pilihan dalam satu menu (breadth besar), 
semakin sedikit tingkat kedalamannya (depth kecil)
•
Semakin sedikit pilihan dalam satu menu (breadth kecil), semakin
banyak tingkat kedalamannya (depth besar)

5. Connected Menus
•
Connected menu adalah jaringan menu yang saling terhubung
•
Perpindahan antar menu tidak terbatas pada struktur hierarki
•
Pengguna dapat berpindah ke sebagian besar atau semua menu 
dalam jaringan
•
Connected menu dapat bersifat:
Siklikal: perpindahan dua arah antar menu dimungkinkan
Asiklikal: perpindahan hanya satu arah
•
Tingkat konektivitas menunjukkan seberapa banyak menu saling
terhubung melalui berbagai jalur
•
Pada menu hierarkis, fitur kembali ke menu sebelumnya atau ke menu 
utama juga merupakan bentuk connected menu yang terbatas

6. Event-Trapping Menus
•
Menyediakan kontrol terhadap status dan parameter sistem di 
latar belakang (background) sementara pengguna sedang
mengerjakan tugas utama (foreground task).
•
Menu ini merupakan sekumpulan menu simultan yang 
diterapkan di atas menu hierarkis.
•
Dalam sistem grafis, misalnya, terdapat menu simultan, menu 
bar, dan hierarki secara bersamaan — yaitu menu bar beserta
pull-down menu-nya.
© Politeknik Statistika STIS
Serve one of three functions
• Menu dapat langsung mengubah parameter pada 
lingkungan saat ini (misalnya membuat teks
menjadi bold)
• Menu dapat menjalankan fungsi tertentu tanpa
meninggalkan lingkungan saat ini (misalnya
pemeriksaan ejaan/spell check)
• Menu juga dapat keluar dari lingkungan saat ini dan 
memindahkan pengguna ke lingkungan baru
(misalnya Exit)
© Politeknik Statistika STIS

4. Ordering of Menu Items
1. Frekuensi penggunaan
Pilihan yang paling sering digunakan sebaiknya ditempatkan di awal
Pilihan yang jarang digunakan ditempatkan di akhir
Frekuensi dapat ditentukan melalui analisis tugas atau data 
penggunaan nyata
2. Urutan alami (Natural ordering)
Gunakan urutan alami jika item memiliki susunan tertentu
Contoh: bab buku, hari dalam seminggu, atau bulan dalam setahun
3. Urutan numerik (Numeric ordering)
Digunakan untuk pilihan yang berkaitan dengan angka
Contoh: ukuran huruf, baud rate, atau jumlah piksel
© Politeknik Statistika STIS

•
atau tingkat kepentingan

9. Keyboard Shortcuts
• When a person is using a keyboard, it is inefficientto
continually take mouseactions.
• Keyboard shortcuts allow actions to be taken using the  
keyboard as well as the mouse.
• In a study, keyboard shortcuts have been found to be 
significantly faster and more accurate than mouseclicks,  and 
preferred by nearly all users (Jorgensen et al.,  2002).
• Shortcuts include keyboard equivalents and keyboard  
accelerators.
© Politeknik Statistika STIS
Keyboard Equivalents
• To facilitate keyboard selection of a menu choice,  each menu item 
should be assigned a keyboard  equivalent mnemonic.
• The mnemonic should be the first character of the  menu item’s
description.
If duplication exists in first characters, use another  character in the 
duplicated item’sdescription.
Preferably choose the first succeeding consonant.
• Designate the mnemonic character by underliningit.
• Use industry-standard keyboard accessequivalents  when theyexist.
© Politeknik Statistika STIS
Standard Keyboard Equivalents
© Politeknik Statistika STIS
Keyboard Accelerators
•
Untuk item yang sering digunakan, sediakan keyboard accelerator 
agar pemilihan lebih cepat
•
Accelerator dapat berupa satu tombol fungsi atau kombinasi tombol
•
Sebaiknya tidak lebih dari dua tombol ditekan secara bersamaan
•
Gunakan tanda plus (+) untuk menunjukkan kombinasi tombol
•
Pisahkan accelerator dari deskripsi menu dengan tiga spasi
•
Jangan gunakan accelerator untuk:
•
menu yang memiliki submenu bertingkat (cascaded menus),
•
pop-up menus
•
Gunakan keyboard accelerator standar industri jika tersedia
© Politeknik Statistika STIS

Tujuan

Tear-off Menu
• A tear-off menu is a pull-down menu that can be  positioned 
anywhere on the screen for constant referral.  As such, it 
possesses all the characteristics of a pull- down.
• It may also be called a pushpin, detachable, or roll-up  menu.
• Its purpose is to present alternatives or choices to the  screen 
user that are needed infrequently at some times  and heavily at 
other times.
• Tear-off menus are most useful for expert users.
